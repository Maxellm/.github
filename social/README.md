# maxellm social kit

Brand assets generated from the site's design tokens: paper `#F4F3EC`, ink `#14140F`,
sand `#C8B89A`, dark `#0C0C0E`, cream `#F6F1E4`. Typeface: **Outfit** (Google Fonts).
Platform copy (bios, about text, post captions) is in [`COPY.md`](COPY.md).

| Folder | Contents | Use |
|---|---|---|
| `logo/` | Mark and wordmark as SVG + transparent PNG (ink / cream / sand). `icon-*-tile.svg` are the rounded app-icon tiles. | Anywhere you need the logo on your own background. Ink on light, cream on dark. |
| `icons/dark/`, `icons/paper/` | Rounded-tile icons at 16–1024 px + `favicon.ico`. | Favicon, PWA, app stores, Instagram highlight covers, Slack/Notion workspace icons. |
| `profile/` | Square profile pictures in paper and dark. | `universal-1000` fits every platform; sized variants for LinkedIn (400), Instagram (320), X (400), GitHub (500). |
| `banners/` | Cover images, each in paper and dark. | LinkedIn company 1128×191, LinkedIn personal 1584×396, X 1500×500, Facebook 820×312, YouTube 2560×1440 (safe area respected), GitHub OG 1280×640, email signature 1200×300. |
| `posts/` | Ready-to-post graphics. | Instagram square 1080×1080 (paper + dark), portrait 1080×1350, story 1080×1920, LinkedIn 1200×627. |

Rules of thumb: minimum clear space around the mark is half its height; never recolor outside
ink / cream / sand; on photos use the dark variants; do not stretch the wordmark.
